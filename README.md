# Saikumar Cherku — Interactive Portfolio

Open `index.html` in a modern browser. No build tools required.

Use **Change Mode** at the top of the page to select **Classic**, **My Creative Side**, or **My Spidey Side**.

- **Classic**: Cursor-based code effects. Press `/` to use the interactive developer console.
- **My Creative Side**: Muted editorial palette, playful kinetic shapes, drawing cursor effects, and the Throw Shapes button or `D` shortcut.
- **My Spidey Side**: Interactive web effects, `W` web shots, and the secret Spider Lab mission.

You can also use the keyboard shortcuts `1`, `2`, and `3` to change views. The site supports mobile and prefers-reduced-motion behavior.

The original portrait and local backgrounds are included in `assets/`. Project images are illustrative, not actual screenshots. Review employment dates and the public contact address before deployment.
